# 「맨 땅에 헤딩」 스토리 정본

> 작성일: 2026-09-02 · 톤: **담담한 미스터리** (사용자 확정) · 코드 반영: `js/story.js` (이 문서와 1:1 — 텍스트를 고치면 story.js도 같이)
> 원칙: 설명하지 않는다. 짧은 문장. 여백. 유령·괴물 없음 — 공포가 아니라 여운. 스토리는 루프를 방해하지 않는다(전부 스킵 가능한 밀도).

## 0. 세계관 한 장

오래전 닫힌 광산이 다시 열렸다. 이유는 아무도 말해주지 않는다.
그 광산에는 **기록자**라 불리는 선대 광부의 흔적이 남아 있다 — 이름은 전해지지 않고, 벽과 쪽지에 남긴 기록만 전해진다. 그는 "바닥을 보고 오겠다"고 내려갔고, 마지막 기록은 60m 바닥에 있다. 돌아갔는지는 아무도 모른다.
플레이어는 새 광부다. 내려가면서 기록자의 흔적을 줍는다. 엔딩에서 플레이어는 **살아서 돌아온 두 번째 사람**이 되고, 다음 사람을 위해 자신의 기록을 남긴다.

미스터리 축(끝까지 설명 안 함): ① 기록자는 돌아갔는가 ② 광산은 왜 닫혔고 왜 다시 열렸는가 ③ "아래가 따뜻하다"는 것의 의미.

## 1. 오프닝 (첫 실행 1회, IntroScene)

```
광산이 다시 열렸다.
마지막으로 닫힌 게 언제인지, 아무도 정확히 모른다.

남아 있는 기록은 하나뿐이다 —
"바닥을 보고 오겠다."

곡괭이를 받았다. 아래는 어둡다.
```
하단: `— 클릭해서 내려간다 —`

## 4. 사망 서브텍스트 (랜덤 1종)

1. 한 칸이 과했다.
2. 산소는 경고했다. 두 번은 하지 않았다.
3. 욕심은 무게가 없다. 그래서 다들 지고 내려간다.
4. 광산은 아무 말이 없다.
5. 기록자에게도 이런 날이 있었을 것이다.

## 5. 지상 기지 플레이버 (하단 한 줄)

- 초반(총 런 3회 미만): 기존 힌트 안내 유지("가스도 붕괴도 흙과 똑같이 생겼다…")
- 이후 랜덤 로테이션:
  1. 갱도 입구에서 바람이 올라온다. 아래 어디선가 문이 열려 있는 것처럼.
  2. 장비는 거짓말하지 않는다. 산소도 그렇다.
  3. 지상은 오늘도 흐리다. 광산 안이 더 밝을 때가 있다.
  4. 곡괭이 소리는 위에까지 올라오지 않는다.
- 조건부(우선 적용): 유물 1개 이상 확정 — "기록자의 물건은 이상하게 가볍다." / 엔딩 후 — "바닥을 본 사람은 이제 둘이다."

## 6. 엔딩 보강 (EndingScene)

기존 구성(기록 3개 전문 + "그리고 당신은 살아서 돌아왔다." + 통계) 뒤에 한 줄 추가:

```
광산은 다시 조용하다.
다음에 내려올 사람을 위해, 당신도 기록을 남겼다.
```

→ 플레이어가 다음 "기록자"가 되는 순환 구조로 마무리. 미스터리는 풀지 않는다.
