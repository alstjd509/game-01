> 작성일: 2026-09-02 · **전제: v0.2 재미 재판정 통과 시 발효** (폐기되면 이 문서는 무효, 슬롯 빌더로 이동)

## 0. 게임명

- **한글(확정): 맨 땅에 헤딩** — 관용구(무모한 도전) + 문자 그대로 땅에 머리부터 들어가는 게임. 구 가칭 「한 칸 더」는 UI 문구·스토리 모티프("한 칸만 더")로 남긴다.
- 영문(itch.io용, 후보): **Headfirst** (추천 — 무모하게 뛰어든다는 뉘앙스 일치, 한 단어), Groundbreaker, One More Dig. → 출시 준비 때 확정.

## 1. 엔딩 — 유물 3개 + 미니 스토리

- 유물은 깊이 단계별 **고정 배치**: ① 25m 부근 · ② 45m 부근 · ③ 60m(최심부). 각 유물이 "이 깊이까지 왕복할 장비"라는 중간 목표가 된다.
- **유물은 들고 귀환해야 확정.** 사망하면 유물은 광산에 남는다(다음 런에 같은 위치에서 재도전) — push-your-luck의 정점: 유물을 쥔 순간이 게임에서 가장 긴장되는 귀환길이어야 한다.
- 유물마다 **기록 조각 1~2줄**(선대 광부의 기록, 획득 시 표시 + 지상 기지에서 다시 보기):
  - 기록 ① "먼저 내려간 사람의 곡괭이가 여기 박혀 있었다. 날이 다 나갔는데, 발자국은 더 아래로 이어진다."
  - 기록 ② "벽에 새겨져 있다 — '돌아갈 산소를 남겨라.' 새긴 사람은 돌아갔을까."
  - 기록 ③ "마지막 기록: '바닥이 보인다. 한 칸만 더.' …기록은 여기서 끝난다."
  - (초안 — 폴리싱 때 다듬기. 텍스트 톤: 가벼운 미스터리, 설명 최소)
- 3개 회수 → **엔딩 화면**: 기록 전문 + 통계(총 런 수·사망 수·총 수확·최고 깊이) → **무한 모드 해금**(엔딩 후에도 계속 파기, 기록 갱신용).

## 2. 층 구성 (ROWS 64 유지, 층별 팔레트 구분)

| 층 | 깊이 | 구성 | 신규 요소 |
|---|---|---|---|
| 1층 표토 | 1~20m | 흙·돌·구리·(6m~)은·가스·캡슐 — 현행 | 학습 구간, 변화 없음 |
| 2층 암반대 | 21~40m | 돌 밀도↑, 은 중심, 금 시작 | **붕괴 타일** 등장 · **단단한 암반**이 층 하부(38~40m)에 벽처럼 밀집 = 곡괭이 게이트 · **유물①(25m)** |
| 3층 심부 | 41~64m | 금 중심, 가스·붕괴 밀도 최고 | **암흑**(타일 내용 은폐) · **보석** 극희귀 등장 · **유물②(45m)·유물③(60m)** |

## 3. 신규 타일 스펙 (가설 수치)

| 타일 | 효과 | 힌트 | 비고 |
|---|---|---|---|
| 붕괴 타일 | 밟으면 산소 −15 | 가스와 **별도 계열**("우르릉", 각인·HUD에 색 구분 표시) | 힌트 2종이 되며 추론 게임 깊어짐. 램프는 둘 다 탐지 |
| 단단한 암반 | **곡괭이 Lv2 미만이면 굴착 불가**, Lv2 비용 4 | 외형으로 식별(진한 돌) | 하드 게이트 — 2층 하부에 줄지어 배치해 심부 진입을 장비 진척에 묶는다 |
| 암흑 | 3층에서 광물·캡슐 표시가 숨겨짐(전부 흙처럼 보임) | 램프 **Lv2(신규)** 구매 시 심부에서도 표시 | 타일이 아니라 층 규칙. 정보 게임의 최종 단계 |
| 보석 | 가치 **20G** | 항상 보임(암흑에서는 램프 Lv2 필요) | 3층 극희귀(~0.8%). "저거 하나면 산소통 산다"는 유혹 장치 |

## 4. 신규·확장 업그레이드 (가설 수치)

| 장비 | 효과 | 비용 |
|---|---|---|
| 가방 (신규) | 사망 시 손실 70% → 50% → 30% | 20 · 50 |
| 스캐너 (신규) | 런당 1회 발동, 주변 5×5의 가스·붕괴 위치 3초 공개 | 35 |
| 램프 확장 | Lv2 추가: 심부 암흑에서도 광물·캡슐 표시 | 55 |
| 산소통·곡괭이 | 기존 곡선 유지 (곡괭이 Lv2가 암반 게이트 열쇠가 됨) | 기존 |

## 5. 밸런스 방향

- 목표 완주 시간 **2~4시간** (Digseum·Nodebuster 모델). 업글 총비용 ≈ 700~900G 수준에서 유물 3개 왕복이 가능하도록 곡선 조정.
- 층별 수익 기대치가 "다음 업글 1개"를 향해 수렴하게: 1층 런 ≈ 10~20G → 2층 런 ≈ 30~60G → 3층 런 ≈ 80~150G(보석 포함 시 스파이크).
- 유물 귀환길이 가장 위험해야 함 — 유물 층 주변의 가스·붕괴 밀도를 국소적으로 높이는 "유물 경비 구역" 검토.

## 6. 구현 순서 (재판정 통과 후)

1. 층 팔레트·확률 곡선 분리 + 붕괴 타일(힌트 2종화) — 코어 확장
2. 단단한 암반 게이트 + 곡괭이 연동
3. 유물 3개 + 기록 텍스트 + 엔딩 화면 + 무한 모드
4. 암흑 규칙 + 램프 Lv2 + 보석
5. 가방·스캐너
6. 밸런스 패스(§5 목표로 수치 조정) → 재미 확인 → 폴리싱 단계(아트·사운드·juice)로
