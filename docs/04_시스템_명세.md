## 1. 코드 맵

| 파일 | 역할 |

## 2. 규칙 명세 (v0 — 그레이박스)

### 2.1 굴착·이동
- 조작: **마우스 클릭**(플레이어의 상하좌우 4방향 인접 타일, 대각선·원거리 무시) + **키보드 방향키·WASD**(동일 규칙 — 2026-09-02 추가).
- 안 파인 타일 = 굴착 + 그 칸으로 이동. 파인 타일 = 이동.
- 런 시작 시 조작 안내 문구가 표시되고, 첫 행동과 함께 사라진다.
- HUD 영역(y < HUD_H)의 클릭은 게임 입력으로 처리하지 않는다.
- 위로 파는 것도 허용(맵 경계 안에서). 귀환은 버튼으로만 처리한다.

### 2.2 산소 (턴 자원)
- 시작 산소 = `O2_BASE + O2_PER_TANK × 산소통Lv` (§3).
- 소모: 이동 1 · 흙/광물/가스 굴착 1 · 돌 굴착 `STONE_COST_BY_PICK[곡괭이Lv]`.
- 가스 타일을 파면 추가로 `GAS_PENALTY` 소모(즉시).
- **산소 캡슐**(보이는 타일)을 파면 `O2_CAPSULE`만큼 회복 — 최대 산소 초과 불가 (2026-09-02 조정 1회).
- 산소 ≤ 0 이 되는 순간 사망 처리. 산소 비율 30% 미만이면 게이지가 빨간색이 되고, **처음 30% 이하로 떨어지는 순간 경고 배너**("더 갈까, 귀환할까?")가 런당 1회 뜬다 — 죽음을 "예고된 선택"으로 만들기 위함.

### 2.3 광물·수확
- 구리/은/금을 파면 즉시 런 수확(loot)에 가치 가산. 광물은 타일 위 작은 사각형으로 **항상 보인다**(경로 계획 대상).
- 수확은 런 중에는 미확정 상태 — 귀환해야 골드로 확정된다.

### 2.4 가스와 힌트 (차별화 핵심)
- 가스 타일은 **흙과 동일한 외형**(숨은 위험). 파는 순간 발동·소멸.
- 힌트: 플레이어의 현재 위치 기준, **안 파인 인접 타일 중 가스 개수**를 HUD에 표시("쉭쉭… 인접 가스 ×N").
- 탐지 방향: 램프 Lv0 = 4방향, Lv1 = 8방향(대각 포함).
- **방문 각인**(2026-09-02 조정 1회): 플레이어가 지나간 모든 칸에 그 칸 기준 가스 카운트 숫자가 남는다(0은 비표시). 가스가 파이거나 터지면 전체 각인을 재계산한다. 여러 칸의 숫자를 조합해 가스 위치를 추론하는 지뢰찾기식 정보 게임.

### 2.5 귀환·사망 정산
- 귀환(버튼, 언제든 무료): 수확 100% 골드 확정 → 지상.
- 사망(산소 0): 수확 × `DEATH_KEEP`(내림) 확정. 사망 화면은 ① 손실 내역 ② **"귀환만 했어도 +XG 확정이었다" 리캡**(욕심의 대가를 숫자로 명시) ③ **[다시 잠수] 1클릭 즉시 재런** / [지상 기지] 선택지 제공 (2026-09-02 조정 1회).
- 공통: 런 수 +1, 최고 깊이 갱신, 저장.

### 2.6 상점 (지상 기지)
- 업그레이드 3종: 산소통(최대 산소 +10/Lv), 곡괭이(돌 비용 3→2→1), 램프(힌트 4방→8방).
- 골드가 비용 이상일 때만 버튼 활성. 구매 즉시 저장. 레벨 상한 도달 시 "MAX".
- "기록 초기화" 링크 = 메타 전체 리셋(개발·판정용).

### 2.7 저장
- localStorage 키 `hankandeo_v0`, 메타만 저장(런 중 상태는 저장 안 함 — 새로고침 = 런 포기와 동일).
- localStorage 접근은 전부 try/catch — 막힌 환경에서도 게임은 동작(진행만 휘발).

### 2.8 맵 생성
- 크기 `COLS × ROWS`. 0행은 지표(파인 상태).
- 깊이 d(행 번호)에 비례하는 확률 곡선(§3)으로 가스→돌→구리→은→금→캡슐 순서로 판정, 나머지는 흙.
- **은·금 군집**(2026-09-02 조정 1회): 생성 후 은·금마다 35% 확률로 인접 흙 1칸에 같은 광물을 복제 — 화면에 보이는 유혹(갈등 재료)을 만든다.
- **첫 재미 10초 보장**: 1~3행 중앙 3열(3~5열)에서 가스 제거, [1,4]·[2,3]에 구리 강제 배치(이미 광물이면 유지).

## 3. 수치 테이블 (정본 = js/config.js, 2026-09-02 스냅샷)

| 키 | 값 | 의미 |
|---|---|---|
| COLS × ROWS | 9 × 64 | 맵 크기 (0행 = 지표) |
| TILE / HUD_H | 44px / 64px | 렌더 크기 |
| O2_BASE / O2_PER_TANK | 30 / +10 | 시작 산소 / 산소통 레벨당 |
| MOVE_COST / DIRT_COST | 1 / 1 | 이동 / 흙·광물·가스 굴착 |
| STONE_COST_BY_PICK | [3, 2, 1] | 곡괭이 Lv별 돌 굴착 비용 |
| GAS_PENALTY | 8 | 가스 추가 산소 손실 |
| DEATH_KEEP | 0.3 | 사망 시 수확 유지 비율(내림) — 0.5→0.3 (조정 1회) |
| O2_CAPSULE | 10 | 산소 캡슐 회복량 (최대치 초과 불가) |
| VALUE | 구리 1 · 은 3 · 금 8 | 광물 가치(G) |
| 산소통 비용 | 10·25·60·140·300 | 최대 Lv5 |
| 곡괭이 비용 | 15·40 | 최대 Lv2 |
| 램프 비용 | 20 | 최대 Lv1 |
| 가스 확률 | min(0.18, 0.05+d×0.004) | d = 행 깊이 — 밀도 상향 (조정 1회) |
| 돌 확률 | min(0.30, 0.06+d×0.004) | |
| 구리 확률 | max(0.02, 0.11−d×0.001) | 얕을수록 흔함 |
| 은 확률 | d<6이면 0, min(0.09, (d−6)×0.004) | 6m부터 |
| 금 확률 | d<16이면 0, min(0.07, (d−16)×0.0035) | 16m부터 |
| 캡슐 확률 | 0.025 | 깊이 무관 (조정 1회) |
| 은·금 군집 | 35%로 인접 흙에 복제 | 조정 1회 |

디버그: URL `?o2=N` → 시작 산소를 N으로 강제(사망 흐름 테스트용).

## 4. 씬 흐름

```
main.js: runs === 0 ? Mine 먼저 (첫 실행 즉시 플레이) : Shop 먼저
Mine ── 귀환/사망 정산(doFinish: 골드 확정·저장) ──▶ Shop(런 요약 표시)
Shop ── 잠수 시작 ──▶ Mine (새 맵 생성)
Shop ── 구매 ──▶ scene.restart (같은 요약 유지)
```
