## 1. 코드 맵

## 2. 규칙 명세 (v0 — 그레이박스)

### 2.1 굴착·이동
- 조작: **마우스 클릭**(플레이어의 상하좌우 4방향 인접 타일, 대각선·원거리 무시) + **키보드 방향키·WASD**(동일 규칙 — 2026-09-02 추가).
- 안 파인 타일 = 굴착 + 그 칸으로 이동. 파인 타일 = 이동.
- 런 시작 시 조작 안내 문구가 표시되고, 첫 행동과 함께 사라진다.
- HUD 영역(y < HUD_H)의 클릭은 게임 입력으로 처리하지 않는다.
- 위로 파는 것도 허용(맵 경계 안에서). 귀환은 버튼으로만 처리한다.
- 렌더링(폴리싱 1차): 타일 = **바탕 이미지**(층별 흙·돌·암반·굴·지표) + **오버레이 이미지**(광석·캡슐·유물) 2장 구조. 가스·붕괴는 오버레이가 없어 그 층의 흙과 완전히 동일하게 보인다. 플레이어는 광부 도트 스프라이트.

### 2.2 산소 (턴 자원)
- 시작 산소 = `O2_BASE + O2_PER_TANK × 산소통Lv` (§3).
- 소모: 이동 1 · 흙/광물/가스 굴착 1 · 돌 굴착 `STONE_COST_BY_PICK[곡괭이Lv]` · **단단한 암반** `HARDROCK_COST` (콘텐츠 2단계).
- **암반 하드 게이트**: 곡괭이 레벨이 `PICK_REQ_HARDROCK` 미만이면 암반은 굴착 자체가 불가 — 산소 소모·이동 없이 거절 메시지만 표시.
- 가스 타일을 파면 추가로 `GAS_PENALTY`, **붕괴 타일**을 파면 `COLLAPSE_PENALTY` 소모(즉시). 붕괴는 2층(암반대)부터 등장한다 (콘텐츠 1단계).
- **산소 캡슐**(보이는 타일)을 파면 `O2_CAPSULE`만큼 회복 — 최대 산소 초과 불가 (2026-09-02 조정 1회).
- 산소 ≤ 0 이 되는 순간 사망 처리. 산소 비율 30% 미만이면 게이지가 빨간색이 되고, **처음 30% 이하로 떨어지는 순간 경고 배너**("더 갈까, 귀환할까?")가 런당 1회 뜬다 — 죽음을 "예고된 선택"으로 만들기 위함.

### 2.3 광물·수확
- 구리/은/금/**보석**을 파면 즉시 런 수확(loot)에 가치 가산. 광물은 타일 위 작은 사각형으로 보인다(경로 계획 대상) — 단 **암흑 층에서는 §2.10 규칙**을 따른다.
- 수확은 런 중에는 미확정 상태 — 귀환해야 골드로 확정된다.

### 2.4 숨은 위험과 힌트 (차별화 핵심 — 콘텐츠 1단계에서 2계열로 확장)
- 숨은 위험 2종: **가스**(−8)와 **붕괴**(−15). 둘 다 **그 층의 흙과 동일한 외형**, 파는 순간 발동·소멸.
- 힌트도 2계열로 분리: HUD에 **초록 "쉭쉭… 가스 ×N"** / **주황 "우르릉… 붕괴 ×N"** 두 줄 표시.
- 탐지 방향: 램프 Lv0 = 4방향, Lv1 = 8방향(대각 포함). 두 계열 모두 동일 적용.
- **방문 각인**: 지나간 모든 칸에 카운트 숫자가 남는다 — 칸당 2개(왼쪽 초록=가스, 오른쪽 주황=붕괴, 0은 비표시). 위험이 파이면 전체 재계산. 여러 칸 숫자를 조합해 위치를 추론하는 지뢰찾기식 정보 게임.

### 2.5 귀환·사망 정산
- 귀환(버튼, 언제든 무료): 수확 100% 골드 확정 → 지상.
- 사망(산소 0): 수확 × `DEATH_KEEP_BY_BAG[가방Lv]`(내림) 확정 — 손실 70% → 50% → 30% (가방이 보험 역할, 콘텐츠 5단계). 사망 화면은 ① 손실 내역 ② **"귀환만 했어도 +XG 확정이었다" 리캡** ③ **[다시 잠수] 1클릭 즉시 재런** / [지상 기지] 선택지 제공.
- 공통: 런 수 +1, 최고 깊이 갱신, 저장.

### 2.6 상점 (지상 기지)
- 업그레이드 6종: 산소통(최대 산소 +10/Lv), 곡괭이(돌 비용 3→2→1, **Lv2 = 암반 굴착 해금**), 램프(힌트 4방→8방→**Lv2 = 심부 암흑 투시**), **가방**(사망 손실 70→50→30%), **스캐너**(런당 1회 능동 정보), **승강기**(출발 깊이 해금, §2.12).
- 골드가 비용 이상일 때만 버튼 활성. 구매 즉시 저장. 레벨 상한 도달 시 "MAX".
- "기록 초기화" 링크 = 메타 전체 리셋(개발·판정용).

### 2.7 저장
- localStorage 키 `hankandeo_v0`, 메타만 저장(런 중 상태는 저장 안 함 — 새로고침 = 런 포기와 동일).
- 메타 필드: `gold`·`tankLv`·`pickLv`·`lampLv`·`bagLv`·`scanLv`·`elevLv`·`startDepth`·`bestDepth`·`runs` + `relics[3]`·`deaths`·`totalEarned`·`endingSeen` + (스토리) `introSeen`·`notes[8]`.
- localStorage 접근은 전부 try/catch — 막힌 환경에서도 게임은 동작(진행만 휘발).

### 2.9 유물·엔딩 (콘텐츠 3단계)
- 유물 3개는 `RELICS` 고정 위치(25m·45m·60m)에 생성 — **아직 확정 회수하지 못한 것만** 매 런 같은 자리에 다시 생긴다.
- 유물 타일은 항상 보이는 보라색 큰 표식. 파면 즉시 "들고 있는" 상태(HUD `✦유물 ×N`), 굴착 비용은 흙과 동일.
- **귀환해야 확정**(meta.relics 기록). **사망하면 들고 있던 유물을 잃고** 광산에 남는다 — 사망 화면에 전용 문구 표시.
- 귀환으로 새 유물을 확정하면 지상 기지에서 **기록 조각 오버레이**(해당 유물의 텍스트) 표시.
- 3개 모두 확정된 "귀환" 순간 → **엔딩 씬 직행**(기록 3개 전문 + 통계: 총 런·사망·총 수확·최고 깊이) → `endingSeen` 기록 → 이후 **무한 모드**(상점 헤드라인에 표기, 게임은 계속 플레이 가능). 엔딩은 1회만 표시.

### 2.10 암흑·보석 (콘텐츠 4단계)
- **암흑**: `dark: true`인 층(심부 41m~)에서는 램프 레벨이 `LAMP_REQ_DARK` 미만이면 **광물·캡슐 표식이 숨겨진다**(흙과 동일하게 보임). 램프 Lv2 구매 시 심부에서도 표시.
- 예외: **유물은 암흑에서도 항상 보인다**(목표물이므로 — 엔딩 진행이 막히면 안 됨).
- 층 경계 라벨에 상태 반영: 램프가 모자라면 "— 심부 41m **· 어둠** —"으로 표시(구매 동기 예고). 라벨은 런 시작 시점 기준.
- **보석**: 가치 20G, 심부 전용 극희귀(0.8%). 항상 보이는 광물 취급이지만 암흑 규칙의 적용을 받으므로, 사실상 램프 Lv2가 있어야 노릴 수 있는 유혹 장치.

### 2.11 스캐너 (콘텐츠 5단계)
- 스캐너 보유(Lv1) 시 HUD에 **[스캔] 버튼**(귀환 옆) 표시. **런당 1회** 발동.
- 발동: 플레이어 중심 `SCAN_RANGE` 반경(2 = **5×5**)의 안 파인 **가스·붕괴 위치를 색으로 공개**(가스 초록·붕괴 주황 하이라이트) — `SCAN_REVEAL_MS`(3초) 후 소멸.
- 범위 내 위험이 없으면 "주변이 깨끗하다" 플로팅 텍스트.
- 발동 후 버튼은 "스캔 완료"로 비활성. 설계 의도: 힌트(수동 추론)와 달리 **"언제 쓸까"를 고민하는 능동 정보** — 유물 귀환길 직전에 아껴 쓰는 그림.

### 2.13 스토리 장치 (docs/07_스토리.md가 텍스트 정본)
- **오프닝**: `introSeen`이 false면 IntroScene 1회 표시 → 클릭 → 광산.
- **쪽지 타일**: `HK.STORY.NOTES` 고정 위치 8개, **미수집만** 생성. 항상 보임(암흑 예외 — 스토리는 막지 않는다). 굴착 비용 1, **줍는 즉시 확정+저장**(사망 무관 — 정보를 노가다로 만들지 않는다). 획득 시 하단 패널 4.5초(런 안 끊김).
- **기록 열람**: 지상 기지 "📜 기록" 버튼 → 확정 유물 기록+수집 쪽지를 깊이순 오버레이로.
- **사망 서브텍스트**: `DEATH_LINES` 랜덤 1종. **상점 하단 문구**: 총 런 3회 미만 = 힌트 튜토리얼 고정, 이후 플레이버 로테이션(유물 보유·엔딩 조건부 우선).
- **엔딩 마무리**: 통계 뒤 `ENDING_CLOSER`(플레이어가 다음 기록자가 되는 순환).

### 2.12 승강기·출발 깊이 (밸런스 패스 1차 — `06_밸런스_노트.md`)
- 승강기 업그레이드: Lv1 = **21m 출발** 해금(40G), Lv2 = **41m 출발** 해금(120G, **곡괭이 Lv2 필요** — 상점에서 조건 미달 시 잠금 표시).
- 상점의 "출발 깊이" 선택 버튼(0m/21m/41m)으로 선택, `meta.startDepth`에 저장. 해금 범위를 넘는 값은 `HK.state.startDepth()`가 0으로 강제.
- 광산 시작 시 해당 깊이의 [행,4] 타일을 파인 상태로 만들고 그 자리에서 시작. 카메라는 즉시 그 깊이를 비춘다. `maxDepth`도 출발 깊이에서 시작.
- 설계 의도: 매 런 반복되는 하강세 제거(없으면 심부 유물 도달률 2%) — 한 런 1~3분 유지의 핵심 장치.

### 2.8 맵 생성 — 층(스트라타) 기반 (콘텐츠 1단계)
- 크기 `COLS × ROWS`. 0행은 지표(파인 상태).
- **3개 층**: 표토(1~20m) → 암반대(21~40m) → 심부(41~64m). 층마다 흙 팔레트가 다르고, 화면에 **층 경계 라벨**("— 암반대 21m —")이 표시된다.
- 타일 판정: 그 깊이가 속한 층의 확률표(§3, 정본 = `config.js`의 `STRATA`)로 가스→붕괴→돌→구리→은→금→캡슐 순서 단일 roll, 나머지는 흙.
- **은·금 군집**: 생성 후 은·금마다 35% 확률로 인접 흙 1칸에 같은 광물을 복제 — 화면에 보이는 유혹(갈등 재료).
- **암반 게이트**(콘텐츠 2단계): `HARDROCK_GATE` 설정대로 39행 전체 + 38·40행 35%를 단단한 암반으로 덮어써 심부 진입을 곡괭이 Lv2에 묶는다. 암반은 항상 보이는 벽(어두운 청회색).
- **첫 재미 10초 보장**: 1~3행 중앙 3열(3~5열)에서 숨은 위험(가스·붕괴) 제거, [1,4]·[2,3]에 구리 강제 배치(이미 광물이면 유지).

### 층별 생성 확률 (콘텐츠 1단계 — 정본 = `config.js`의 `STRATA`)

셀 형식: `기준값 +행당증가` — 실제 확률 = 기준값 + 증가량 × (d − 층시작). `(Nm~)`는 그 깊이부터.

| 층 | 깊이 | 가스 | 붕괴 | 돌 | 구리 | 은 | 금 |
|---|---|---|---|---|---|---|---|
| 표토 | 1~20m | 0.05 +0.004 | — | 0.06 +0.004 | 0.11 −0.001 | 0 +0.004 (6m~) | — |
| 암반대 | 21~40m | 0.11 +0.001 | 0.03 +0.0015 | 0.18 +0.002 | 0.05 | 0.09 | 0.01 +0.0015 |
| 심부 | 41~64m | 0.14 +0.0015 | 0.07 +0.001 | 0.18 | 0.03 | 0.05 | 0.06 +0.001 |

층 테마: 표토 = 학습·구리 / 암반대 = 은 중심·돌 벽·붕괴 등장 / 심부 = 금 중심·위험 밀도 최고·**암흑·보석**.
심부 전용: 보석 0.008(고정). 층별 흙 팔레트·경계 라벨·암흑 여부는 `STRATA`의 `dirtColor`·`name`·`dark`에서 나온다.

디버그: URL `?o2=N` → 시작 산소를 N으로 강제(사망 흐름 테스트용).

## 4. 씬 흐름

```
main.js: introSeen false → Intro 먼저 / runs === 0 → Mine (즉시 플레이) / 그 외 → Shop
Intro ── 클릭 ──▶ Mine
Mine ── 귀환/사망 정산(doFinish: 골드·유물 확정·통계·저장) ──▶ Shop(런 요약 + 새 유물 기록 오버레이)
Mine ── 유물 3개 모두 확정된 귀환 && !endingSeen ──▶ Ending(기록 전문+통계) ──▶ Shop(무한 모드)
Mine ── 사망 오버레이의 [다시 잠수] ──▶ Mine (즉시 재런)
Shop ── 잠수 시작 ──▶ Mine (새 맵 생성)
Shop ── 구매 ──▶ scene.restart (같은 요약 유지)
```
