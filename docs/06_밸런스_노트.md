# 밸런스 노트 — 1차 패스 (수학적 이상값 제거)

> 작성일: 2026-09-02 · 방법: 실제 게임 코드(mapgen·config)를 그대로 사용하는 **몬테카를로 시뮬레이션**(400회/케이스, 페이지 내 실행).
> 봇 기준: 아래 3방향 중 최저 비용 선택(돌 회피), 힌트는 못 읽음(맹굴착) — 사람보다 다소 약한 플레이어 근사.
> 2차 패스는 사용자 통플레이 피드백으로 진행 예정.

## 1. 발견한 이상값 (수정 전)

**엔딩이 수학적으로 막혀 있었다.** 매 런 새 맵이라 하강 비용이 매번 다시 들고(60m 편도 기대 ~150 산소), 최대 산소가 80(탱크 Lv5)이라:

| 목표 | 장비 | 도달률 (수정 전) |
|---|---|---|
| 유물① 25m | 탱크2·곡괭이1 | 61% — 적정 |
| 유물② 45m | **최대 장비**(탱크5·곡괭이2) | **32%** ⚠ |
| 유물③ 60m | **최대 장비** | **2%** ❌ 사실상 불가 |

원인: "귀환은 무료"지만 **하강은 매 런 유료** — 깊이가 깊어질수록 하강세가 산소 예산을 전부 삼킨다.

## 2. 처방 (2026-09-02 적용)

1. **승강기(elev) 업그레이드 신설** — 장르 표준 해법(모터로드식 이동 수단). 한 런 1~3분 설계를 유지하면서 하강세만 제거.
   - Lv1 (40G): 21m(암반대) 출발 해금 · Lv2 (120G): 41m(심부) 출발 해금
   - **Lv2 구매 조건: 곡괭이 Lv2** — "암반을 뚫은 자만 승강기를 내린다"(게이트 의미 보존)
   - 상점에 출발 깊이 선택 UI(0m/21m/41m, 선택 저장)
2. **산소통 후반 비용 완화**: Lv4·5 = 140·300 → **110·220** (심부 왕복 장비를 현실적 시간 안에)

## 3. 수정 후 도달률 (동일 시뮬레이션)

| 목표 | 경로 | 도달률 |
|---|---|---|
| 유물① 25m | 21m 출발 + 탱크0(기본) | **97%** — 승강기 Lv1이 유물①의 열쇠 |
| 유물② 45m | 41m 출발 + 탱크2 | **100%** |
| 유물③ 60m | 41m 출발 + 탱크3 / 4 / 5 | **53% / 70% / 79%** — 최종 목표다운 도전 난이도 (사람은 힌트·스캐너·가방으로 상향) |

## 4. 경제 곡선 (분석값, 참고)

- 타일당 기대 수익/비용(G/산소): 표토 ≈ 0.10 · 암반대 ≈ 0.26 · 심부 ≈ 0.36 — 깊을수록 효율↑ = 내려갈 이유 ✔
- 런 기대 수익: 표토 초반 ~3G → 암반대 밴드 채굴 ~10-15G → 심부 밴드 ~20-25G(+보석 스파이크 20G)
- 엔딩 필수 투자 추정: 탱크3~4(95~205) + 곡괭이2(55) + 승강기(160) ≈ **310~420G** → 중후반 런 수익 기준 25~35런 → 학습·사망 포함 **완주 목표 2~4시간 안착** 추정
- 탱크 Lv5(220G)·가방·스캐너·램프는 선택 투자 + 무한 모드 싱크

## 5. 통플레이에서 확인할 것 (2차 패스 질문지)

1. 표토 초반(승강기 전) 그라인드가 지루하지 않은가? — 지루하면 표토 광물 밀도 상향 검토
2. 승강기 가격(40/120)이 체감상 적절한가?
3. 심부 위험 밀도(가스 15%+붕괴 8%)가 "빡세지만 읽으면 피할 만"한가, 그냥 운빨인가?
4. 유물③ 왕복이 몇 번의 시도 끝에 성공했나? (3~6회 사망이 설계 의도)
5. 완주까지 실제 소요 시간
