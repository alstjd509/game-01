## 1. 스네이크 서바이버

- **루프**: 필드의 먹이를 먹으면 몸 파츠(=무기)가 붙고, 파츠가 자동 공격. 길수록 강하지만 조작 난도 상승(리스크=파워).
- **유사작**: **SNKRX**(스팀, 2021 — 몸이 유닛으로 구성된 스네이크 오토배틀러, 상점에서 유닛 구매). 컨셉 재미가 이미 검증됐다는 증거인 동시에, 그대로 만들면 클론이 되는 리스크.
- **강점**: 규칙 자체에 긴장(욕심 vs 생존)이 내장. GIF 한 장 전달력 최고. 도형만으로 코어 검증 가능.
- **리스크·공수 함정**: 파츠(무기) 종류를 늘릴수록 공수 급증 → 1차 목표는 5~8종으로 제한. SNKRX와의 차별화 각을 정하고 시작해야 함.
- **그레이박스 1주 목표**: 이동 + 먹기 + 파츠 1종 자동공격 + 적 웨이브 → "몸이 길어질수록 긴장되는가?"
- **차별화 각도**: (a) 상점이 아니라 **필드 드랍을 직접 골라 먹는** 빌드(어느 먹이로 향할지가 곧 조작 리스크), (b) 자기 몸·지형 충돌을 살려 고전 스네이크의 긴장 유지, (c) 웹 특화 1~3분 초압축 런.

## 2. 원버튼 미니뱀서

- **루프**: 마우스 커서만 따라다니는 이동, 자동 공격, 3분 생존, 레벨업 3택.
- **유사작**: Vampire Survivors, Magic Survival(모바일 원형), 20 Minutes Till Dawn + 웹 클론 다수.
- **강점**: 실패 확률이 가장 낮고 구현 참고 자료가 압도적으로 많음. 학습 1호로 최적.
- **리스크**: 차별화가 가장 어려움 — itch.io에서 "또 뱀서네"로 스쳐 지나갈 가능성. 죽음이 조작보다 빌드 탓이라 "내 탓" 감각은 약한 편.
- **그레이박스 1주 목표**: 이동 + 무기 1종 + 적 1종 + 레벨업 3택 → "3분이 짧게 느껴지는가?"
- **차별화 각도**: 하나는 필수 — 예: 무기가 전부 이동 방식과 결합(이동 궤적이 곧 공격), 또는 화면 밖으로 못 나가는 초소형 아레나.

## 3. 머지 디펜스

- **루프**: 수박게임식 드롭·합치기로 유닛 생성 → 유닛이 웨이브 자동 방어. 큰 유닛 합성 쾌감 + 붕괴 직전 역전.
- **유사작**: 수박게임(합치기 물리), 랜덤 다이스(머지×디펜스), 하이퍼캐주얼 머지 디펜스 다수.
- **강점**: 합성 쾌감은 보상 체감이 가장 직관적. 방치形로도 확장 여지.
- **리스크·공수 함정**: **밸런스 작업량 최대** — 유닛 티어 × 웨이브 곡선 × 물리 배치가 서로 얽힘. 그레이박스 단계에서 재미 판정이 늦게 나옴(티어 3~4개는 있어야 쾌감 확인 가능). 운 비중이 커서 "내 탓" 감각 약함.
- **그레이박스 1주 목표**: 드롭·머지 + 유닛 1계열 공격 + 웨이브 → "언제 합칠지 고민이 생기는가?"
- **차별화 각도**: 물리 낙하(수박게임)와 디펜스의 결합 자체는 아직 흔치 않음 — 배치 위치가 사거리·시야에 영향을 주는 식.

## 4. 딥 다이버

- **루프**: 1~3분 아래로 채굴, 연료 소진 전 귀환 → 자원으로 장비 업글 → 더 깊이. "조금만 더" vs "지금 귀환" 갈등.
- **유사작**: Motherload(플래시 고전), Dome Keeper·Wall World(채굴+방어), Mr.Mine(방치 채굴).
- **강점**: 메타 성장 궁합 최고(장비 트리 = 진행 그 자체). 귀환 갈등이라는 명확한 감정 축.
- **리스크·공수 함정**: 광물 분포·깊이별 지형·장비 트리 등 **콘텐츠 제작량이 겉보기보다 큼**. 전투 없으면 단조로워지기 쉬워 위험 요소(낙석·가스 등) 추가가 사실상 필수.
- **그레이박스 1주 목표**: 굴착 + 연료 게이지 + 귀환 판정 + 상점 1개 → "더 갈까 말까 갈등이 생기는가?"
- **차별화 각도**: 한 손(마우스만) 조작 채굴, 또는 실시간이 아닌 반턴제 "한 칸씩" 파기로 퍼즐성 부여.

## 5. 탄막 회피 러너

- **루프**: 공격 없이 회피만. 생존 시간 = 점수·재화 → 런 사이 업그레이드(대시·슬로우·자석).
- **유사작**: Just Shapes & Beats(회피+리듬), 고전 플래시 탄막 피하기류.
- **강점**: **공수 최소** + 죽음 원인이 가장 명확(순수 내 탓) → "한판 더" 순도 최고. 그레이박스=거의 완성본.
- **리스크**: "초소형 지양" 방침에 걸릴 수 있음 — 볼륨을 만들려면 패턴 수·모드가 많이 필요. 전달력도 스크린샷으로는 평범해 보임.
- **그레이박스 1주 목표**: 이동 + 탄 패턴 3종 + 사망 순간 리플레이 → "아깝다! 가 나오는가?"
- **차별화 각도**: 회피 자체에 자원을 결합 — 아슬아슬하게 스칠수록(그레이즈) 재화 획득 같은 리스크 보상.

## 6. 궤도 슈터

- **루프**: 행성 주위 자동 공전, 클릭으로 방향 반전·사격. 타이밍 숙련형.
- **강점**: 조작 최소(클릭 1개) 대비 숙련 깊이. 구현도 가장 단순한 축.
- **리스크**: 스크린샷·말로 재미가 전달되기 어려움(직접 잡아야 앎). 메타 성장을 붙이면 순수 타이밍 게임의 맛이 희석되는 긴장 관계.
- **그레이박스 1주 목표**: 공전 + 반전 + 적 1종 → "클릭 타이밍에 손맛이 있는가?"
- **차별화 각도**: 리듬 요소 결합(적 웨이브가 박자에 맞춰 등장) 등.

## 7. 변형·조합 아이디어 (브레인스토밍 시드)

1. **스네이크 × 딥 다이버** — 아래로 파고드는 뱀. 먹은 광물이 몸 파츠(드릴·무기)가 되고, 깊이가 곧 난이도·보상.
2. **머지 × 뱀서** — 필드 드랍 젬을 자석으로 끌어와 인벤토리에서 머지 → 무기 진화. 뱀서의 빌드에 합성 쾌감을 결합.
3. **탄막 회피 + 그레이즈 경제** — 회피 전용인데 탄을 아슬아슬 스칠수록 재화가 쌓임 → 리스크=수익 구조를 회피 게임에 이식.

## 10. 취향 데이터 반영 재평가 (2026-09-02)

### 발견 — 사용자가 수십 시간 이상 박힌 게임

**다키스트 던전 · 슬레이 더 스파이어 · 발더스 게이트 · 엑스컴.** 공통 DNA:

- 전부 **런/캠페인 기반 빌드 구성** (덱·파티·분대) — "다음엔 다른 조합"이 재도전 동기
- 전부 **리스크 관리·확률 아래서의 의사결정** (횃불·스트레스, 카드 픽, 명중률, 영구 죽음)
- 전부 **턴제·저(低)피지컬** — 조작 반사신경이 아니라 **판단**이 실력
- → 초기 설문의 "아케이드 한판 더" 선택과 달리, 실제 중독 이력은 **의사결정형 로그라이트**에 있다. 기준에 **⑥피지컬 의존도(낮을수록 취향 부합)** 를 추가한다.

### 재평가 결과

- **탄막 회피·궤도 슈터: 사실상 탈락** — 순수 피지컬, 취향 근거 없음.
- **스네이크 서바이버: 1→4위** — 트렌드 부합은 최상이지만 실시간 피지컬 비중이 큼. 살리려면 "어느 먹이를 먹을지 = 빌드 선택"이라는 의사결정 축을 전면에 세우는 하이브리드 조건.
- **머지 디펜스: 유지(3위권)** — 배치·타이밍 의사결정 중심이라 취향 부합. 밸런스 공수 리스크는 그대로.
- **딥 다이버: 급상승** — 단, **턴제 push-your-luck 변형**으로. 상세 아래.
- **신규 후보 추가: 슬롯/주사위 빌더** — 슬더스 계보 직격. 상세 아래.

### 신규 후보 A — 「한 칸 더」 (딥 다이버의 턴제 push-your-luck 변형)

- **루프**: 그리드 광산을 클릭으로 **한 칸씩** 파 내려간다. 타일마다 비용(산소/내구)·보상(광물)·리스크(가스·붕괴)가 보이거나 반쯤 가려져 있고, 깊을수록 보상과 리스크가 함께 커진다. 언제든 "귀환"하면 수확 확정, 욕심 부리다 죽으면 절반 손실. 귀환 → 장비 업글 → 더 깊이 → 심층 유물 회수 = **엔딩 있는 완결형**.
- **취향 부합**: "한 칸만 더 vs 지금 귀환" = 다키스트 던전의 횃불 딜레마와 동형. 죽음은 100% 내 욕심 탓.
- **트렌드 부합**: "끝이 있는 짧은 인크리멘탈"(트렌드 조사 §4) 정중앙 + 깊이 파고드는 화면이 GIF 전달력도 있음.
- **공수**: 실시간 물리·게임필 튜닝 불필요, 콘텐츠 = 타일·아이템 테이블 → **S+~M−로 원안(M)보다 감소.** 그레이박스 = 그리드+숫자만으로 당일 검증 가능.
- **유사작**: Motherload(실시간)·Dome Keeper(실시간)와 달리 턴제 그리드 채굴은 상대적으로 빈 공간. Digseum(클리커)과도 구분됨.

### 신규 후보 B — 「슬롯 빌더」 (심볼 시너지 로그라이트)

- **루프**: 스핀마다 슬롯판의 심볼 시너지로 골드 획득, N스핀마다 임대료(장벽) 지불. 런 중 심볼을 사서 덱(=슬롯 풀)을 빌드. Luck be a Landlord → Balatro로 이어진 검증된 계보.
- **취향 부합**: 슬더스식 "픽 하나로 빌드가 굴러가는" 쾌감 직격. 피지컬 0.
- **차별화 각**: 원조(LbaL)는 심볼 배치가 랜덤 — **심볼의 판 위치를 직접 배치**하게 하면(인접 시너지) 엑스컴식 배치 전략이 얹힌다.
- **공수**: UI+심볼 25~30개+시너지 테이블 = M−. 재미 검증은 종이 프로토로도 가능할 만큼 빠름.
- **리스크**: Balatro 이후 유사작 러시로 경쟁 밀도 높음. 숫자 중심이라 GIF 전달력은 약한 편.

### 갱신 추천 순위

1. **「한 칸 더」(턴제 채굴 push-your-luck)** — 취향×트렌드×공수 3박자. 유사작 밀도도 낮음.
2. **「슬롯 빌더」** — 취향 직격도 최고, 공수 통제 최고. 경쟁 밀도가 감점.
3. **머지 디펜스** — 배치형 취향 부합, 밸런스 공수 부담.
4. **스네이크 서바이버** — 트렌드 최적이나 피지컬 비중이 취향과 어긋남(하이브리드 조건부).
