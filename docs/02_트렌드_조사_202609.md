# 게임 트렌드 조사 (2026-09)

> 조사일: 2026-09-02 · 목적: game-01 컨셉 선정에 반영할 시장 신호 수집 (웹게임 + 스팀 인디)
> 소스 신뢰도: MCV(업계지)·SensorTower·Wikipedia·주요 게임 매체 기준. SEO성 블로그·커뮤니티발 수치(예: 특정 게임 1,000만 장 주장)는 미검증이라 제외함.

## 1. 웹게임 시장 — 우리 "웹 우선" 전략에 순풍

- HTML5 게임 출시가 **2025년 상반기에만 15,000개** — 전년 대비 약 3배, 2023년 대비 4.9배. 시장이 커지는 동시에 **공급(경쟁)도 폭발** 중.
- **Poki 월간 활성 사용자 1억 명**(2020년 1,000만 → 10배), 월 방문 1.2억. CrazyGames 월 방문 6,100만. 5년간 트래픽 +569% / +673%.
- 브라우저 게임 시장 규모 2026년 약 **$19.3B** → 2032년 $28.4B 전망 (업계 추정).
- 평균 세션이 **약 30분** — 웹 = 스낵 유저만 있다는 통념과 다름. 참여 루프만 좋으면 오래 붙잡을 수 있음.
- 시사점: 방향 결정(웹 우선, itch → 포털)이 시장 흐름과 일치. 단, 공급 폭발 때문에 **훅 없는 평범한 게임은 묻힌다.**

## 2. 포털(Poki·CrazyGames)이 원하는 것 — 나중 제출 대비 지금부터 반영 가능

- **"처음 10초 안에 재미"** — 긴 튜토리얼·느린 로딩 게임은 심사·성과 모두 불리.
- 기술 기준(CrazyGames): 초기 다운로드 50MB 이하, SDK 통합 시 전체 250MB 이하. → JS+Phaser 선택이 유리(유니티 웹 대비 초경량).
- 잘 되는 장르: 퀵세션 액션, .io 멀티, 캐주얼 퍼즐. 연령별 분화 — 10대=경쟁·io, 고연령=퍼즐.
- 멀티·공유 요소가 있으면 가점 (SDK 초대 기능 등). 솔로 게임이라도 **점수 공유·리더보드**는 고려 가치.
- 브라우저 최다 플레이 유형: 데일리 퍼즐(Wordle류), .io, 고전(크롬 공룡·솔리테어).
- 시사점: 그레이박스 설계 단계부터 "**리트라이 3초, 첫 재미 10초**"를 명시적 요구사항으로 삼자.

## 3. 스팀 인디 — "익숙한 캐주얼 메커닉 × 로그라이트" 전성기

- 2025년에 **인디 8개가 동접 10만 돌파(역대 최다)** — 인디 상방이 열려 있음.
- **Ball x Pit**(2025, Devolver 퍼블리싱): 벽돌깨기(브레이크아웃) × 뱀서식 성장 × 기지 건설. 출시 직후 스팀 판매 상위권, 한때 보더랜드 4·Megabonk보다 잘 팔림. → **"고전 캐주얼 메커닉에 로그라이트 성장을 접붙이는" 공식의 최신 대박 사례.**
- **Megabonk**(2025-09, 솔로 개발): 3D 뱀서라이크 + 밈 에너지로 대박. → 뱀서류는 포화 논란 속에서도 **훅(비주얼·밈·손맛)만 있으면 여전히 터짐.**
- 2026년에도 로그라이트·덱빌딩 초강세 지속: **Slay the Spire 2**(3월 EA, 500만 장+), **Mewgenics**(첫 주 100만 장).
- 코옵 클립 트렌드: R.E.P.O.·PEAK — 친구 코옵 + 방송 클립 확산 + **$10 이하 저가**로 시청자의 즉시 구매 유도. (우리 트랙과는 거리 있지만 "저가+클립되는 순간" 설계는 참고)
- 니치 공략이 생존율 높음 — 경쟁 최심 장르(범용 RPG·액션) 정면승부 회피.

## 4. 방치형·인크리멘탈 — "끝이 있는 짧은 게임" 니치 확립

- **Nodebuster**(2024), **Digseum**(2025): 2~5시간이면 **완결**되는 초저가 인크리멘탈이 스팀에서 압도적 긍정 평가(90%+)로 니치 확립. "끝날 때를 아는 클리커"가 셀링 포인트.
- 시사점: 우리 공수 프로필(1인·1~2개월)과 정확히 맞는 성공 모델. **"짧고 완결되는 성장 게임"을 7번 후보로 추가할 가치** 있음. 웹 데모 → 스팀 $3~5 확장 경로도 검증돼 있음.

## 5. 우리 후보 6개에 주는 시사점

| 후보 | 트렌드 부합 | 근거 |
|---|---|---|
| 1 스네이크 서바이버 | **◎ 최상** | "익숙한 캐주얼 메커닉(스네이크) × 로그라이트" = Ball x Pit이 증명한 공식 정중앙. 뱀서 수요 지속(Megabonk). 10초 훅 전달도 용이. itch에서도 유사 매시업(Snake-a-roid 등)이 주목받는 공간 |
| 2 원버튼 미니뱀서 | ○ | 수요는 확실하나 HTML5 공급 폭발 속 클론 차별화가 더 어려워짐 — 훅 하나 필수 |
| 3 머지 디펜스 | ○ | 포털 고연령층의 캐주얼 퍼즐 수요와 접점. 다만 밸런스 공수 리스크는 그대로 |
| 4 딥 다이버 | ○+ | Digseum(채굴×수집×성장)이 유사 정서로 성공 — 채굴+성장 니치는 검증됨. 인크리멘탈 쪽으로 기울이면 §4 흐름에 올라탐 |
| 5 탄막 회피 러너 | ○ | 포털의 퀵세션 액션 기준(10초 훅·3초 리트라이)에 정확히 부합. 볼륨 약점은 여전 |
| 6 궤도 슈터 | △ | 훅 전달이 약하다는 기존 약점이 "공급 폭발" 환경에서 더 아픔 |
| (신규 검토) 7 미니 인크리멘탈 | ○+ | "끝이 있는 2~5시간 성장 게임" — 공수 최적합, 스팀 확장 경로 검증. 단 사용자의 아케이드 취향과 거리 확인 필요 |

## 6. 결론 — 트렌드 반영 후 추천 유지·조정

1. **스네이크 서바이버 1순위 유지·강화** — 트렌드(캐주얼 메커닉×로그라이트)가 추천 근거를 보강함. SNKRX 차별화 각 전제는 동일.
2. **딥 다이버 소폭 상승** — "짧은 완결 성장" 니치와 결합하면 (반턴제·인크리멘탈 감성) 공수도 줄고 트렌드에도 올라탐.
3. 전 후보 공통 요구사항 추가: **첫 재미 10초·리트라이 3초·초경량 로딩** (포털 제출 대비).
4. 점수·기록 공유(리더보드 or 결과 카드 이미지)는 폴리싱 단계 검토 항목으로.
