# 「맨 땅에 헤딩」 캐릭터 설계 — 해금·능력·서사

> 작성일: 2026-09-02 · 사용자 결정: 4인 라인업 · 도전과제형 해금 · 표준 스토리 분량(오프닝+사망+엔딩 한 줄)
> 원칙: **순수 상위호환 금지** — 능력은 플레이 스타일 변형(트레이드오프 필수). 해금은 골드가 아니라 **플레이가 열쇠**.
> 코드 정본: 능력·해금 = `config.js CHARS` + `state.js checkUnlocks` / 서사 = `story.js CHAR_STORY` / 스프라이트 = `textures.js`

## 1. 라인업

| 캐릭터 | 해금 조건 | 능력 | 트레이드오프 | 컨셉 |
|---|---|---|---|---|
| **신입** | 기본 | 표준 | — | 현재의 플레이어. 오프닝(광산이 다시 열렸다)의 주인공 |
| **고물상** | 누적 수확 300G | 광물 가치 +25% | 최대 산소 −10 | 돈만 보는 자 — 짧고 굵은 러시 플레이 |
| **겁쟁이** | 산소 5 이하로 **생환** 1회 | 사망 손실 −20%p(상한 90% 보존) · 산소 15% 추가 경고 | 광물 가치 −15% | 오래 살아남는 안전 플레이 — 해금 조건 자체가 "아슬아슬한 생환" 체험 |
| **기록자** | **엔딩 달성** | 암흑 투시 내장 · 힌트 8방향 내장 | 상점 가격 +25% | 최종 해금. 미스터리의 당사자(인지 아닌지) — 정보는 완벽하지만 지상과의 거래가 서툴다 |

## 2. 능력 구현 축 (config 파라미터 보정)

- `valueMult` — 광물 가치 배율(반올림). 구리 1G는 반올림 특성상 고물상도 1G(의도 — 상위 광물일수록 이득)
- `o2Bonus` — 최대 산소 가감(하한 15)
- `deathKeepBonus` — 사망 보존율 가산(가방과 합산, 상한 0.9)
- `secondWarn` — 산소 15% 2차 경고
- `hint8` / `darkSight` — 램프 없이 8방 힌트 / 심부 암흑 투시
- `shopMult` — 상점 가격 배율(반올림)

## 3. 해금 판정 (`state.checkUnlocks`, 런 정산·엔딩 시 호출)

- 고물상: `totalEarned ≥ 300`
- 겁쟁이: 귀환(사망 아님) 시점의 잔여 산소 ≤ 5
- 기록자: `endingSeen`
- 해금 순간: 상점 요약에 "⛏ 새 광부 해금 — {이름}" / 엔딩 화면에도 표시

## 4. UI

- 상점 헤드라인 아래 **"광부: {이름} ▾"** 버튼 → 픽커 오버레이(이름·능력·해금 조건, 고물상은 진행도 `n/300G` 표시)
- 선택 시 캐릭터 **전용 인트로 1회**(charIntroSeen) → 상점 갱신. 스프라이트 팔레트 스왑(신입 노랑/파랑 · 고물상 주황/갈색 · 겁쟁이 초록 · 기록자 보라)

## 5. 캐릭터 서사 (정본 = story.js CHAR_STORY, 톤: 담담한 미스터리 유지)

**고물상** — 인트로: "빚은 지상에 있고, 금은 아래에 있다. / 오늘도 저울은 아래로 기운다." · 사망: "금 몇 덩이가, 아직 저 아래에."
**겁쟁이** — 인트로: "죽지 않는 게 이기는 거다. / 아버지도 그랬고, 그 아버지도 그랬다. / 그 아버지의 아버지는… 광산에 있다." · 사망: "그러니까 내려오지 말자니까."
**기록자** — 인트로: "당신은 이 광산을 아는 것 같다. / 갱도의 굽이가, 어둠의 냄새가 낯설지 않다. / 내려간다. 이번에는." · 사망: "또다시." · **엔딩 변형: "광산은 다시 조용하다. / 이번에는, 돌아왔다."** ← 미스터리 순환의 페이오프(기록자의 정체는 끝까지 명시하지 않는다)

## 6. 밸런스 메모 (통플레이 후 확인)

- 고물상 산소 −10은 초반(탱크 Lv0~1)에 크게 아픔 — 해금 시점(300G)이면 탱크 2~3이라 체감 적정 예상
- 겁쟁이 −15% 가치는 무한 모드 파밍에서 불리 — 안전 vs 효율 축이 유지되는지 확인
- 기록자 상점 +25%는 엔딩 후 해금이라 실질 부담 낮음 — 무한 모드 신규 회차용 난이도 옵션 성격
