# 「한 칸 더」 미니 기획서 (v0)

> 작성일: 2026-09-02 · 상태: 그레이박스 개발용 초안 — 재미 판정 전까지 여기 적힌 수치는 전부 가설이다.
> 원칙 준수: 1~2페이지, 문서보다 손맛. 그레이박스 판정 후에만 확장한다.

## 1. 한 줄 정의

**턴제 그리드 채굴 push-your-luck 로그라이트.** "한 칸만 더 팔까, 지금 귀환할까"를 반복하며 장비를 키워 심층 유물을 회수하는, **끝이 있는** 완결형 성장 게임. (웹, 마우스 클릭만, 한 런 1~3분, 전체 완결 2~4시간)

- 감정 축: **욕심 vs 확정.** 죽음은 100% 내 욕심 탓 → "아, 한 칸만 덜 팔걸. 다시!"
- 취향 근거: 다키스트 던전 횃불 딜레마 + 엑스컴식 정보 아래 리스크 판단 + 슬더스식 런 간 빌드(장비)

## 2. 코어 루프

```
[지상] 장비 확인 → [잠수] 클릭으로 인접 타일을 한 칸씩 굴착 (산소 소모)
  → 광물 획득 / 위험 타일 조우 → 매 순간 "더 팔까 / 귀환할까"
  → [귀환] 수확 확정·판매 → [상점] 장비 업글 → 더 깊이 재잠수
  → [죽음 시] 수확물 50% 손실 후 귀환 (즉시 재도전 가능, 리트라이 3초)
  → 최심층 유물 회수 = 엔딩
```

### 굴착 규칙 (v0)
- 플레이어는 갱도를 따라 이동하며, **인접 타일 클릭 = 굴착 + 이동.** 실시간 요소 없음.
- **산소** = 턴 자원. 굴착·이동마다 감소, 0이 되면 사망 처리(수확 50% 손실).
- **정보 게임(차별화 핵심)**: 위험 타일은 지뢰찾기식 **인접 힌트**를 흘린다 — 가스 포켓 옆 타일은 "쉭쉭" 표시, 붕괴 타일 옆은 균열 표시. 램프 업글로 힌트 반경 확장. → 운이 아니라 **추론 실력**으로 리스크를 읽게 만든다.

### 타일 종류 (v0 — 그레이박스는 ★만)
| 타일 | 효과 |
|---|---|
| ★ 흙 | 산소 1로 굴착 |
| ★ 돌 | 산소 3 (곡괭이 업글로 감소) |
| ★ 광물 구리/은/금 | 가치 1 / 3 / 8 |
| ★ 가스 포켓 | 밟으면 산소 −8, 인접 힌트 있음 |
| 산소 캡슐 | 산소 +10 |
| 붕괴 타일 | 밟으면 즉사급 피해, 인접 힌트 있음 |
| 유물 조각 | 엔딩 재화, 심층에만 |

### 깊이 층(스트라타)
깊을수록 광물 가치↑·위험 밀도↑·새 타일 등장. v0는 3개 층(0~10m / 10~25m / 25m+ 유물층).

## 3. 메타 성장 (상점, v0 5종)

| 장비 | 효과 | 비용 곡선(가설) |
|---|---|---|
| 산소통 | 최대 산소 30 → +10/레벨 | 10·25·60·… |
| 곡괭이 | 돌 굴착 비용 3→2→1 | 15·40 |
| 램프 | 힌트 반경 1→2→3 | 20·50 |
| 가방 | 사망 시 손실 50%→30%→10% | 15·35 |
| 로프 | 현재 위치에서 즉시 귀환 1회/런 | 30 |

- 업글이 "더 깊이"를 열고, 깊이가 "더 큰 욕심"을 만든다 — 성장이 곧 긴장 증폭기.
- 엔딩: 유물 3개 회수. 이후 무한 모드는 폴리싱 단계 검토(스코프 밖).

## 4. 요구사항 (트렌드 조사에서 확정된 것)

- **첫 재미 10초**: 시작 즉시 굴착 가능, 첫 광물이 3칸 안에 보이게 배치.
- **리트라이 3초**: 사망 → 결과 요약 1화면 → 클릭 한 번에 상점/재잠수.
- **초경량**: 도형/타일 그래픽, 로딩 수 초 이내. 조작 마우스 온리(모바일 포팅 대비).

## 5. 그레이박스 계획 (1주차)

- 구현: 그리드 렌더+굴착·이동, 산소, ★타일 6종, 귀환/사망 정산, 상점 3종(산소통·곡괭이·램프), 층 1개
- **재미 판정 질문**: ① 귀환 버튼 앞에서 실제로 갈등하는가? ② 죽고 나서 "내 탓, 다시"가 나오는가? ③ 힌트 읽는 재미가 있는가?
- 판정 탈락 시: 힌트 밀도·손실률 조정 1회 재시도 → 그래도 아니면 폐기하고 다음 후보(슬롯 빌더)로.

## 6. 스코프 밖 (v1에서 하지 않는 것)

전투, NPC/스토리, 붕괴 물리 시뮬, 랜덤 이벤트 팝업, 도감, 업적, 무한 모드, 리더보드(폴리싱 때 재검토), 사운드트랙(효과음만).
